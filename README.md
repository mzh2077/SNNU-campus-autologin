## ⚠️ 关于杀毒软件误报（请先读这一段）

**PyInstaller 打包的程序极易被杀毒软件误判为病毒，请放心忽略。**

原因是打包方式决定的：PyInstaller 会把 Python 解释器、
标准库和你的代码**压缩成一个 exe**，这种「单文件塞满代码」的行为
与恶意软件的特征高度重合，因此几乎所有杀毒软件（360、火绒、
Windows Defender 等）都会**默认拦截或提醒**。

这不是本项目特有的问题，任何用 PyInstaller 打包的 Python 程序都会这样。

**处理方式：**

| 杀毒软件 | 操作 |
|---|---|
| Windows Defender | 弹出警告时点「更多信息」→「仍要运行」 |
| 360 / 火绒等 | 开启信任，或把 exe 所在文件夹加入白名单 |
| 无法绕过 | 右键 exe → 属性 → 勾选「解除锁定」→ 应用 |

**为什么可以放心：**

- ✅ **完全开源**（MIT 许可），全部源码在仓库里，可逐行审阅
- ✅ **Windows 下运行核心零第三方依赖**（DPAPI 为系统原生能力），
     无网络上报、无遥测、无后门
- ✅ **行为可查**：所有网络请求都只发往学校门户，无其他目的地
- ✅ **凭据本地加密**：密码经 Windows DPAPI 加密，密文中不含明文
- ✅ 源码可自行验证：用自带的 Python 重新打包亦可

> 如果仍有疑虑，请不要直接运行预编译的 exe，
> 而是 clone 源码后自行运行 `python main.py`，或用 `python build.py` 自己打包。

## 这是什么

命令行小工具：双击即自动登录校园网，连上后自动关闭。支持开机自启动。

打包好的 `校园网自动登录.exe` **无需安装 Python**，任意 Windows 电脑双击即可运行。

## 功能一览

- 自动登录校园网，连上后自动退出
- 可选开机自启，**可在任务管理器「启动」中管理**
- 密码经 Windows DPAPI 加密保存，明文不落盘
- 输入密码时红字提示 + 星号反馈
- 首次设置时校验密码，**错误凭据绝不保存**
- 完整卸载：清理注册表、凭据、配置与程序自身

## 一、直接使用（推荐）

1. 双击 `校园网自动登录.exe`
2. 首次运行会引导你输入**账号**和**密码**，并选择你的网络运营商
3. 接着会询问**是否设置开机自动启动**（默认「是」）
4. 之后每次打开程序，登录完成后会弹出**设置菜单**，可随时管理各项

**换密码 / 换账号**：设置菜单选 `3`，或执行 `校园网自动登录.exe --set`

## 二、两种运行模式

| | 开机自动启动时 | 手动双击打开时 |
|---|---|---|
| 窗口 | 不显示 | 显示 |
| 输出 | 完全静默 | 详细过程 |
| 结束方式 | 登录成功**立即退出** | 弹出设置菜单 |
| 打扰程度 | **无感** | 可交互 |

**开机自启**走 `--quiet` 分支：连上就退，不倒计时、不等待、不弹窗；
失败也只写日志。你完全感觉不到它运行过。

**手动打开**登录完成后会进入设置菜单：

```
==============================================
  设置菜单  v1.0.0
==============================================
  当前账号  ：4266****@mobile
  开机自启  ：已开启

  [1] 开启开机自动启动
  [2] 关闭开机自动启动
  [3] 删除账号信息并重新选择账号登录
  [4] 删除软件及注册项（完全卸载）
  [5] 重新连接校园网（先断开再重新登录）
  [0] 退出
```

### 什么时候用「重新连接校园网」（选项 5）

正常情况下你**不需要**这个选项——程序打开时会自动处理。

它针对这些情况：

- 显示「已在线」但网页打不开（认证状态僵死）
- 想刷新在线时长
- 换了网络环境后重连

它会**先断开当前连接再重新登录**，所以请确认当前没有正在传输的文件。
注意它和选项 3 的区别：选项 3 是换账号（删掉凭据重新填），
选项 5 是同一账号重连（不改任何设置）。

## 三、密码输入与验证

输入密码时会先显示一行**红色提示**：

```
  （输入时屏幕不会显示任何字符，属正常现象）
请输入密码:
```

这是因为密码采用不回显输入（避免被旁人看到或被记录），
输入时屏幕不会出现任何字符。程序会随你按键实时显示星号
`*`、`**`、`***` 作为反馈，让你知道程序正常工作。

### 输入后立即验证

首次使用或修改账号时，输入完会**立即校验密码**：

- **密码正确** → `[√] 密码正确，连接成功！`，然后保存
- **密码错误** → `[×] 密码错误，连接失败。`，可重新输入（最多 3 次）
- **网络不可达** → 提示并询问是否仍要保存（默认否）

**验证不通过的密码绝不会被保存**，也不会留下错误凭据。

> 技术说明：该校有两个不同的系统——
> **snnuportal**（上网认证，账号形如 `学号@运营商`）和
> **校园宽带自助服务系统**（`/zili/`，宽带业务账号）。
> 两者**密码不通用**，因此密码校验只使用 snnuportal 主门户。
>
> 另外：若你当前已连接校园网，程序会跳过密码校验直接放行——
> 因为门户在已登录状态下，即使密码错误也只会显示在线页面，
> 无法据此判断。程序会明确提示"当前已在线，未再验证密码"。
> 若要完整验证密码，请先在浏览器退出校园网后再重新设置。

## 四、开机自启动

首次运行结束时会询问是否开启开机自启，选择「是」后：

- 开机后自动运行并**静默登录**（不弹任何窗口）
- 启动项会出现在 **任务管理器 → 启动 → 启动应用** 中，显示为「校园网自动登录」
- 你可以在那里随时**启用 / 禁用 / 删除**，也可以用命令行控制

管理命令：

| 命令 | 作用 |
|---|---|
| `--autostart` | 开启开机自启 |
| `--no-autostart` | 关闭开机自启 |
| `--autostart-info` | 查看当前状态和启动命令 |

**为什么在任务管理器里能看见？**
程序把启动项写入注册表
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`，
这正是任务管理器「启动」标签页读取的位置。
放在「启动」文件夹或计划任务里的程序是**看不到**的，所以没用那种方式。

另外程序还会同步写入
`...\Explorer\StartupApproved\Run` 的状态字节（`02` = 已启用），
确保任务管理器里显示为「已启用」而非「已禁用」。

写入的是当前用户（HKCU）下的键，**不需要管理员权限**。

> 如果你把 exe 移到了别的位置，启动项路径会失效。
> 程序每次运行都会自动校正路径，也可用 `--autostart` 重新写入。

### 完全卸载

设置菜单选 `4`（或运行后选择卸载），会依次：

1. 关闭开机自启并删除注册表启动项
2. 删除加密的账号信息
3. 删除配置文件与运行日志
4. 删除程序文件本身

由于 Windows 不允许删除正在运行的 exe，程序会安排一个后台进程
在你退出后完成删除，几秒内自动清理干净。

## 六、图标

exe 使用「师」字图标：深青渐变底 + 白色「师」，配色取自校园网门户主题色。

需要修改样式时，改 `make_icon.py` 顶部的参数后重新生成：

```bash
python make_icon.py     # 生成 icon.ico / icon.png
python build.py         # 重新打包并自动应用图标
```

可调参数：

| 参数 | 含义 |
|---|---|
| `TOP_COLOR` / `BOTTOM_COLOR` | 渐变上下色 |
| `TEXT_COLOR` | 文字颜色 |
| `TEXT_RATIO` | 字号占画布比例（越大字越饱满） |
| `CORNER_RATIO` | 圆角半径 = 画布 ÷ 该值 |
| `ICO_SIZES` | ico 内含的尺寸档位 |

> 图标含 16×16 到 256×256 共 7 档，确保在任务栏、任务管理器、
> 桌面小图标等不同大小下都清晰可辨。

运行期数据不在程序目录，而在：
`%LOCALAPPDATA%\CampusAutoLogin\`
├── `credentials.bin`  加密后的账号密码（**非明文**）
├── `settings.json`    运行配置（非敏感）
└── `run.log`          运行日志（不含密码）

另有注册表启动项：
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → 值名 `CampusAutoLogin`

> 程序里随时可以查看这些位置：设置菜单选 `6`。

### 关于卸载时删除密码

用设置菜单的**选项 4（完全卸载）**即可，它会依次清理：

1. 关闭开机自启并删除注册表启动项
2. 删除 `credentials.bin`（**密码凭据**）
3. 删除配置与日志，**并移除整个数据目录**
4. 清理自我卸载留下的临时备份
5. 删除程序文件本身

实测验证卸载后 `%LOCALAPPDATA%\CampusAutoLogin` 目录**已完全消失**。

### 如果你是直接手动删 exe 的

手动删除文件夹**不会**清掉 AppData 里的密码凭据，
因为凭据存在系统数据目录，与程序目录无关。

这种情况下有三种办法清理：

- 运行 `校园网自动登录.exe --purge`（程序还在的话）
- 直接删除目录 `%LOCALAPPDATA%\CampusAutoLogin`
- 程序启动时会自动检测"孤儿凭据"（启动项指向已删除的 exe）并主动提示清理

## 七、门户接口分析（实测结论）

目标门户 `http://202.117.144.205:8603/snnuportal/userstatus.jsp`
经探测为 **深澜 snnuportal 认证系统**（陕西师范大学），关键发现：

| 项目 | 实测结果 |
|---|---|
| 入口 | `/snnuportal/` → 302 → `userstatus.jsp`（统一入口） |
| 已在线时 | 页面含「当前登录账号 / 登录时间 / 断开连接」 |
| 未在线时 | 呈现登录表单 |
| 登录提交 | POST `login.jsp`，字段 `account` / `password` / `yys` |
| 账号格式 | `学号@运营商`，如 `2024010101@mobile` |
| 运营商取值 | `mobile` 移动 / `unicom` 联通 / `telecom` 电信 |
| 备用端点 | `http://202.117.144.205:80/zili/index.php`，字段 `mode=login` / `login` / `passwd` |
| 页面编码 | 主门户 GB2312；`/zili/` 错误响应为 UTF-8（**两者不同**） |
| User-Agent | 必须伪装浏览器，否则返回 **403** |

**踩坑记录**：该门户会拒绝 curl 默认 UA；另外本机若本来在线，任何登录请求
回查页面都显示「已在线」，因此程序会**核验页面上的账号是否等于目标账号**，
避免把密码错误误判成登录成功。

以上全部参数都在 `config.py` 里，**门户改版时只改这一个文件即可**。

## 十、常见问题

**Q：提示「已在线」但网络还是不通？**
A：可能存在多网卡/多账号会话。可用 `--status` 查看当前内网 IP，必要时先在
浏览器退出该账号再运行程序。

**Q：账号要不要加 `@mobile`？**
A：陕西师范大学的账号需带后缀。首次向导选择运营商会自动补全；也可在
`--set` 时直接填完整账号（如 `2024010101@mobile`）。

**Q：exe 被杀毒软件误报？**
A：这是 **PyInstaller 打包程序的通病**，几乎所有杀毒软件都会误判，
因为「把解释器和代码压成一个 exe」的行为与恶意软件特征重合，并非本项目特有。
处理方式：Windows Defender 点「更多信息」→「仍要运行」；
360/火绒等加入白名单即可。
本项目**完全开源、无第三方依赖、不联网上报任何数据**，源码可逐行审阅。
详见开头[「关于杀毒软件误报」](#️-关于杀毒软件误报请先读这一段)。

**Q：想改成学校自己的门户？**
A：把仓库交给 AI，说「读一下源码，帮我们学校适配一下」即可。
通常只需改 `config.py` 一个文件——详见
[「十三、适配你自己的学校」](#十三适配你自己的学校)。

**Q：如何静默运行（不显示窗口）？**
A：`pythonw main.py` 或加 `--quiet` 参数。用 exe 时开机自启已自动走静默模式。

**Q：开机自启会不会弹出黑窗口？**
A：不会。启动项使用 `--quiet` 静默模式，且程序内部把输出重定向到空设备，
连闪一下都不会，实测耗时约 1 秒内静默完成。

**Q：输入密码时屏幕没反应，是不是卡住了？**
A：不是。密码采用不回显输入（防止被旁观者看到或被日志记录），
屏幕本来就不显示字符。输入时会先有一行红色提示，
并随按键实时显示星号 `*` `**` `***` 作为反馈。

**Q：怎么彻底删掉这个软件？**
A：打开程序 → 登录后进入设置菜单 → 选 `4` 确认即可。
它会清理注册表启动项、账号信息、配置日志和程序文件本身。

**Q：任务管理器里找不到「校园网自动登录」？**
A：确认已成功开启（运行 `--autostart-info` 查看状态）。
若显示「已添加，但在任务管理器中被禁用」，说明你在任务管理器里手动禁用过，
重新运行 `--autostart` 即可恢复。

**Q：能贡献我学校的适配吗？**

## 十一、安全说明

- **代码中不含任何真实账号密码**，也没有任何默认值。
- 密码经 **Windows DPAPI**（`CryptProtectData`）加密后存储，密钥绑定当前
  Windows 用户账户；密文中不含明文，程序日志与异常输出均对密码脱敏。
- 程序仅与学校门户通信，不向任何第三方发送数据，**不含任何后门或遥测**。
- **Windows 下运行核心零第三方依赖**（DPAPI 为系统原生能力），
  `requirements.txt` 中列出的均为可选依赖。
- 非 Windows 系统退化为 AES-256（密钥由机器指纹派生），安全性略低。
- 本工具仅在你**已获授权的校园网**上使用，请遵守学校网络管理规定。
- 全部源码以 MIT 许可公开，可逐行审阅。

**Q：怎么彻底删掉这个软件？**
A：打开程序 → 登录后进入设置菜单 → 选 `4` 确认即可。
它会清理注册表启动项、账号信息、配置日志和程序文件本身。

## 十三、适配你自己的学校

> **本项目仅适配陕西师范大学（SNNU）。** 其他学校需要按本节改造。

### 最省事的做法：交给 AI 改造

把本仓库的链接发给 AI（支持读取 GitHub 仓库的 AI 均可），然后说：

> 「读一下这个仓库的源码，帮我们学校（XXXX 大学）的校园网改一下，
> 我们的门户地址是 ……」

AI 会自动完成适配。通常只需改动 `config.py` 一个文件。

### 手动适配：改一个文件即可

绝大多数学校信息集中在 `config.py`，**门户不同时通常只改这一处**：

| 配置项 | 说明 |
|---|---|
| `status_url` | 状态查询地址（登录后能显示"当前账号"的页面） |
| `login_url` | 备用登录端点 |
| `alt_user_field` | 账号输入框的字段名，如 `account` / `userName` |
| `alt_pass_field` | 密码输入框的字段名，如 `password` / `passwd` |
| `alt_yys_field` | 运营商字段名，部分学校无此字段则填 `None` |
| `carrier` | 运营商后缀（`mobile` / `unicom` / `telecom`） |
| `status_encoding` | 门户编码（常见 GB2312 / UTF-8） |

### 各文件职责

```
config.py         门户地址与接口字段 —— 适配其他学校主要改这里
portal_client.py  网络请求、响应解析、结果判定
config_store.py   DPAPI 加密凭据存储
startup.py        注册表开机自启（任务管理器可见）
console_ui.py     控制台彩色输出
main.py           交互流程与设置菜单
```

### 排查提示

若改完仍不生效，先用 `python main.py --test` 自检；
「门户返回内容异常」通常意味着页面结构变了，
需在浏览器打开登录页 F12 查看真实表单字段名。

## 十四、贡献指南
